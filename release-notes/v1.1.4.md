# CatReNet 1.1.4

## New features

- Network -> Layered Layout: a new way to draw a network. Nodes are placed in layers by the generation in which they
  first become available from the food set, with the food at the top, so reactant and product edges point downward.
  Edges that point upward, most importantly catalysis by a molecule that is only produced later, are drawn as curves,
  so the closures of an autocatalytic set stand out. Combined with "Use Multicopy Food Nodes", each copy of a food item
  sits directly above the reaction that uses it. The previous force-directed layout remains available as
  Network -> Force-Directed Layout.
- Force-directed layout: catalyst and inhibitor edges are given a longer desired length than reactant and product
  edges, and edges at highly connected nodes are lengthened so that their neighbors have room. Both can be adjusted in
  the settings panel.
- Edges are now drawn as straight lines. Only edges between the same pair of nodes, feedback edges in the layered
  layout, and edges bent by hand are curved.
- View -> Zoom In/Out Vertically and Zoom In/Out Horizontally, also available as buttons above the network: stretch or
  squeeze the layered layout in one direction. For the force-directed layout, both directions are scaled together.
  These replace the previous Zoom In and Zoom Out items and buttons; holding shift while scrolling also zooms.
- A newly opened file is first drawn with the force-directed layout.

## Bug fixes

- Network -> Stratification Network (Reactions Only) froze the program on most inputs, because the loop that links a
  reaction to the earlier reactions supplying its reactants could never terminate. All three stratification networks
  now link each reaction to what earlier reactions actually produce, treat a two-way reaction as running in the
  direction in which it became available, and the reactions-only network no longer contains molecule nodes.
- Zoom to fit now scales the whole drawing, including labels, to the visible area; it used to measure the wrong
  coordinates and the wrong pane.
- An edge that has been rerouted by dragging it keeps its shape when one of its nodes is moved: the bend now moves,
  turns and scales with the edge instead of being reset.
- Node labels are placed close to their nodes, without covering them, and away from edges, other labels and other
  nodes where possible.

## Known issues

- Long edges in the layered layout may pass through other nodes
