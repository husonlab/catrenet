# CatReNet 1.1.3

## New features

- New Algorithms -> All Maximal U RAFs Algorithm: finds *all* maximal uninhibited RAFs (uRAFs), not just one. It
  examines the maximal RAF for each subset of the inhibiting elements, so it is feasible when the number of inhibiting
  elements is small (a warning is shown above 12). Reactions inhibited by a food item are excluded, and the maximal
  uRAFs are listed in a text tab. The existing U RAF Algorithm, which returns a single uRAF, is unchanged. A new
  example, uRAF-example.crs, demonstrates the feature.
