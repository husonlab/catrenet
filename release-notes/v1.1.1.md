# CatReNet 1.1.1

## New features

- Reactions no longer need to be given an explicit name: any reaction that is entered without a leading
  `name:` is automatically named `r1`, `r2`, ... (auto-generated names never overwrite or collide with names
  that you supplied yourself). This applies to typed input and to files, in the Full and Sparse notations;
  in the Tabbed notation the name is still the first column.

## Bug fixes

- Fixed bug that left the Algorithms -> MU CAF Algorithm, U RAF Algorithm and Run MU CAF Multiple Times...
  menu items greyed out for typed or pasted input that does contain inhibitions. The three items were
  disabled until inhibitions were detected, but inhibitions were only ever detected while running an
  algorithm, so the items could not enable themselves. They are now enabled whenever there is input, and
  report "no inhibitions present" if the input turns out to have none.
- Fixed bug that allowed examples to silently replace each other in a window
